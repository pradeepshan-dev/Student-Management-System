# 🎓 Student Management System

A Python-based **Student Management System** that allows users to manage student records through a simple command-line interface.

The application uses a text file (`SMS.txt`) for persistent storage and provides options to add, view, search, update, and delete student records.

## ✨ Features

- ➕ Add Student
- 👀 View Student Records
- 🔍 Search Student by ID
- ✏️ Update Student Information
- 🗑️ Delete a Student
- 🧹 Delete All Students
- 🆔 Prevents duplicate Student IDs
- 📊 Validates student marks between 0 and 100
- 🔢 Handles invalid numeric input
- 💾 Stores student records in a text file
- 🔄 Loads existing student records when the program starts

## 📋 Student Information

The system stores the following details for each student:

- Student ID
- Student Name
- Roll Number
- Department
- Year
- Marks
